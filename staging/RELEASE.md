Что нового в 1.0.6:

- Ubuntu 26.04 LTS: панель ставится на неё так же, как на 24.04. Обновлять сервер с 24.04 до 26.04 на месте не нужно: поставьте панель на новый сервер и перенесите её копией.
- Свой DNS-сервер на PowerDNS: панель сама отвечает за записи ваших доменов вместо Cloudflare или регистратора. Включается в «Настройки → DNS-сервер», пока не включён, ничего не ставится.
- DNS-провайдеры России: сертификаты на `*.домен` через reg.ru, Selectel, Яндекс Облако, Timeweb Cloud, Beget и RU-CENTER. У reg.ru работают ещё редактор DNS и помощник DNS почты.
- Фильтр запросов к сайтам (WAF) на правилах OWASP CRS: «Безопасность → WAF». После обновления включён режим «Только журнал», блокировку включает владелец.
- Лимиты ресурсов на сайт: вкладка «Ресурсы» с лимитами процессора, памяти и процессов, графиками и местом на диске. Каждый PHP-сайт теперь работает в своём PHP, сайты переезжают на него сами без остановки, лимитов по умолчанию нет.
- Другие движки в один клик: 1С-Битрикс, MODX, Joomla, Drupal и OpenCart в мастере сайта рядом с WordPress.
- Переезд с HestiaCP, FASTPANEL и ispmanager: сайты, базы, cron и сертификаты. Почту с этих панелей пока переносите сами.
- Бот панели в Telegram и MAX отвечает на команды (`/status`, `/sites`, `/alerts`, `/certs`, `/summary`) и присылает запросы Claude Code на подтверждение. Опасные действия подтверждаются только в панели кодом 2FA.
- Метрики для Grafana по адресу `/api/v1/metrics` и публичная страница статуса сайтов для клиентов.
- История проверок доступности хранится 90 дней вместо 30. Базы с MariaDB 11.4 и новее загружаются в MySQL при переезде.

Что пока не проверено вживую:

- Панель на сервере ARM (arm64): архив собирается и проходит тесты, но на настоящем ARM-сервере не запускался.
- 1С-Битрикс: установка через его собственный мастер до рабочего сайта целиком не проверялась.
- Переезд с ispmanager проверен только по его шаблонам, на настоящей панели ispmanager не проверялся. HestiaCP и FASTPANEL проверены на настоящих панелях.
- Записи DNS у reg.ru на настоящем аккаунте reg.ru не проверялись.

Если что-то из этого не работает, напишите, исправим в 1.0.7.

Полный список в [CHANGELOG.md](https://get.xaos.cc/CHANGELOG.md).

Обновить установленную панель можно кнопкой в «Настройки → Обновление», командой `xaoscc update` или установщиком:

```sh
curl -fsSL https://get.xaos.cc/install.sh | sudo bash -s -- --host <адрес> --email <почта> --allow <ваш IP>
```

Настройки и данные остаются на месте.
